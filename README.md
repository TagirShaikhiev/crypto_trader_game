# Crypto Trader Game

## 🎮 Текущее состояние (Прототип)

### Технический стек

- **Клиент:** Phaser 3 + TypeScript
- **Сборка:** Vite
- **AI/Backend:** Google Gemini API (gemini-2.5-flash)
- **Архитектура:** Модульная система
  - `MarketSimulation` - логика рынка
  - `ReputationManager` - управление репутацией
  - `NewsGenerator` - генератор новостей
  - UI компоненты

---

## 📊 Реализованные механики

### 🔄 Игровой цикл

Игра делится на раунды (**"Дни"**). Каждый день состоит из 4 фаз:

#### 1️⃣ Фаза Планирования
- Игровой процесс останавливается
- Игрок открывает модальное окно редактора
- Вручную вписывает **3 заголовка новостей** (последовательно)

#### 2️⃣ Фаза Анализа (AI)
- Массив из 3 заголовков отправляется в Google Gemini
- AI возвращает JSON для каждой новости:
  - **Тип:** `GOOD` / `BAD` / `NEUTRAL`
  - **Сила (Strength):** числовое значение влияния
  - **Длительность (Duration):** время действия эффекта
- Новости сохраняются как "заряженные" кнопки

#### 3️⃣ Фаза Торговли (Активная)
⏱️ **Длительность:** 30 секунд

**Действия игрока:**
- **Активация новостей** — нажатие на кнопки с заготовленными заголовками
- **Торговля** — открытие позиций LONG/SHORT (25%, 50%, MAX от депозита)
- **Случайные события** — система автоматически публикует новости из локальной базы (рыночный шум)

#### 4️⃣ Фаза Итогов
- Все открытые позиции **принудительно закрываются**
- Сохраняется текущее состояние (Баланс, Heat, История цен)
- График следующего дня начинается с точки закрытия предыдущего

---

### 📈 Симуляция рынка

- График формируется **суммой синусоид** (плавные волны, не случайный шум)
- Используется процентное изменение цены (нет отрицательных значений)
- Динамический цвет линии (🟢 рост / 🔴 падение)
- **Auto-Zoom:** камера автоматически центрируется и масштабируется по вертикали

### 🎯 Визуализация событий (Маркеры)

| Иконка | Значение |
|--------|----------|
| 🔼 Зеленый треугольник | Вход в позицию (Buy/Long) |
| 🔽 Красный треугольник | Закрытие позиции (Short) |
| 🟨 Квадрат | Публикация новости |

### 🖥️ Интерфейс (Terminal UI)

```
┌─────────────────┬──────────────────────┬─────────────────┐
│  Левая панель   │       Центр          │  Правая панель  │
├─────────────────┼──────────────────────┼─────────────────┤
│ Лента новостей  │  График + сканлайны  │  📊 Баланс      │
│ (снизу вверх)   │                      │  💰 PnL         │
│                 │  Панель управления   │  🔥 Heat        │
│ Кнопки новостей │  сделками            │                 │
└─────────────────┴──────────────────────┴─────────────────┘
```

### 💰 Экономика

- **PnL (Profit and Loss):** расчёт в реальном времени
  - `(текущая цена - цена входа) × размер позиции`
- **Long/Short:** заработок на росте и падении
- **Heat (Слежка):** увеличивается при публикации новостей

## 🃏 Система новостей (двухуровневая)

### Уровень 1: Базовые категории

| Категория | Эффект | Скорость |
|-----------|--------|----------|
| 🔴 **HACK** | -40% | ⚡ Быстро |
| 🔴 **REGULATION** | -20% | 🐌 Медленно |
| 🟢 **ADOPTION** | +30% | ⚙️ Средне |
| 🟢 **TECH BREAK** | +50% | 🐌 Медленно |

### Уровень 2: Генерация текста

**Игрок выбирает категорию → вводит свой текст**

**Примеры:**
- `[ADOPTION +30%]` "Илон Маск объявил Bitcoin валютой Марса"
- `[HACK -40%]` "Хакеры украли все биткоины и купили пиццу"

**Роль AI:**
- ✅ Предсказуемость (эффект известен из категории)
- ✅ Креатив (игрок пишет безумные заголовки)
- ✅ AI проверяет соответствие категории

## 🧠 Стратегический слой

### 1. 🃏 Сборка колоды
- Много **быстрых эффектов** = рискованно, но точно
- **Медленные сильные эффекты** = нужно угадать тайминг

### 2. 🔥 Экономика Heat
- Можно **грубо выполнить** задание (+70% Heat)
- Или **тонко манипулировать**, смешиваясь с шумом (+30% Heat)
- Высокий Heat = противодействие системы

### 3. 💰 Риск-менеджмент
- Взять **сложное задание** с большой наградой?
- Или **безопасное** с маленькой, чтобы купить апгрейд?

### 4. 🎯 Мета-стратегия
- Инвестировать в **снижение Heat** (стелс-прохождение)
- Или в **мощные карты** (агрессивный стиль)

## 🤖 Роль AI

### 1️⃣ Валидатор категории (строгая роль)

```
Игрок выбрал [HACK] → написал "Илон купил Tesla за биткоины"
❌ AI: "Это не про взлом, выберите другую категорию или BLANK"
```

### 2️⃣ Анализатор BLANK-карт (креативная роль)

```
BLANK: "Инопланетяне используют Dogecoin как топливо"
🎲 AI: NEUTRAL 0% (слишком абсурдно)

BLANK: "JP Morgan тайно купил 10% всех Bitcoin"  
📈 AI: GOOD +25% (правдоподобный позитив)
```

**Механика BLANK-карт** = элемент сюрприза:
- Можешь попытать удачу с безумной новостью
- Или написать правдоподобную для предсказуемого эффекта
- Это твой **"джокер"** в колоде
